# 配る鍵の手順（作者の手の操作。2026-11-20 作者「配る鍵を新しく作る」）

モバイル版の新しい版を、アプリの中から入れられるようにするための手順です。配る APK には、毎回同じ「署名の鍵」を付けます。鍵が変わると、Android は上書きを断ります。引継ぎ書 155〜157章。

- 鍵の合言葉は、チャットにも、このファイルにも書きません。作者が打つのは、パソコンの黒い画面（PowerShell）の中だけです。
- 鍵のファイルは、リポジトリのフォルダーの外に置きます。GitHub へは送りません。

## 1. 鍵を作る（パソコン）

1. 画面の左下の［スタート］（Windows の印）を押す
2. 「powershell」と打ち、出てきた［Windows PowerShell］を押す（黒か青の画面が開く）
3. 次の1行を貼り付けて Enter を押す（鍵を置くフォルダーを作る）

   ```powershell
   New-Item -ItemType Directory -Force "$HOME\novel-ai-mobile-key"
   ```

4. 次の1行を貼り付けて Enter を押す（鍵を作る）

   ```powershell
   & "C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot\bin\keytool.exe" -genkeypair -keystore "$HOME\novel-ai-mobile-key\release.jks" -alias novelai -keyalg RSA -keysize 4096 -validity 36500 -dname "CN=novel-ai-mobile"
   ```

5. 「Enter keystore password:」と出たら、鍵の合言葉を決めて打ち、Enter（打っても字は出ません）。6字以上。忘れないものにする
6. 「Re-enter new password:」と出たら、同じ合言葉をもう一度打ち、Enter
7. 「Generating 4,096 bit RSA key pair …」と出て、次の行に戻ったら、できています

## 2. 鍵の控えを取る（なくすと、すべての端末で入れ直しになります）

1. ［スタート］→「エクスプローラー」と打って開く
2. 上の住所の欄に `%USERPROFILE%\novel-ai-mobile-key` と打って Enter
3. 中の `release.jks` を、USB メモリーか、パソコンの外の置き場（Google ドライブなど）へ写す
4. 鍵の合言葉は、パスワードの管理（ブラウザのパスワードの保存など、作者がふだん使う所）に「novel-ai-mobile の配る鍵」として控える

## 3. 鍵を GitHub の Secrets に入れる（パソコン）

1. の PowerShell の画面で続けます。閉じていたら、1. の 1〜2 でもう一度開きます。

1. 次の1行を貼り付けて Enter（鍵のファイルを Secrets に入れる。画面に何も出なければ入っています）

   ```powershell
   [Convert]::ToBase64String([IO.File]::ReadAllBytes("$HOME\novel-ai-mobile-key\release.jks")) | gh secret set NOVELAI_KEYSTORE_BASE64 --repo nonahisa/novel-ai-mobile
   ```

2. 次の1行を貼り付けて Enter（鍵の名前。秘密ではない）

   ```powershell
   gh secret set NOVELAI_KEY_ALIAS --body novelai --repo nonahisa/novel-ai-mobile
   ```

3. 次の1行を貼り付けて Enter。「? Paste your secret」と出たら、1. で決めた鍵の合言葉を打って Enter

   ```powershell
   gh secret set NOVELAI_KEYSTORE_PASSWORD --repo nonahisa/novel-ai-mobile
   ```

4. 次の1行を貼り付けて Enter。「? Paste your secret」と出たら、同じ合言葉をもう一度打って Enter（この鍵の形では、二つの合言葉は同じです）

   ```powershell
   gh secret set NOVELAI_KEY_PASSWORD --repo nonahisa/novel-ai-mobile
   ```

5. 確かめ：次の1行を貼り付けて Enter。`NOVELAI_KEYSTORE_BASE64`・`NOVELAI_KEY_ALIAS`・`NOVELAI_KEYSTORE_PASSWORD`・`NOVELAI_KEY_PASSWORD` の4つが並べば終わり（値は出ません）

   ```powershell
   gh secret list --repo nonahisa/novel-ai-mobile
   ```

`gh` がうまく動かないときは、ブラウザで入れる道もあります：github.com の nonahisa/novel-ai-mobile を開く → 上の［Settings］→ 左の［Secrets and variables］→［Actions］→ 緑の［New repository secret］→ Name に上の名前、Secret に値 →［Add secret］。鍵のファイルの値（BASE64）は、PowerShell で `[Convert]::ToBase64String([IO.File]::ReadAllBytes("$HOME\novel-ai-mobile-key\release.jks")) | Set-Clipboard` を打つと写しに入るので、Secret の欄に貼る。

ここまで終わったら、母艦に「鍵を入れた」とだけ伝えてください（合言葉は伝えない）。モバイル版のセッションが、最初の Release（`v<版>` のタグ）を作ります。

## 4. AQUOS を入れ直す前に、作品を全部 GitHub へ送る（AQUOS）

いま AQUOS に入っている版は、このパソコンの試しの鍵が付いています。新しい鍵の版へ移るときは、一度アプリを消して入れ直すので、端末の中の作品・書きかけの控え・設定・GitHub のサインイン・AI の鍵が消えます。その前に、次を確かめます。

1. AQUOS のロックを外し、モバイル版のアプリを開く
2. 下のタブの［作品］を押す
3. 作品の札を一つずつ見る。右に「同期済み」と出ていれば、その作品は GitHub に全部あります
   - 「送っていない話：N」か「送っていない変更：N」と出ている作品：その字を押す → 上の［送る］を押す → 「送りました」と出るのを待つ → 左上の［＜］（戻る）で戻る。札が「同期済み」になるまで繰り返す
   - 「競合：N話」と出ている作品：その字を押し、話ごとに［こちら］［あちら］［両方残す］を選んでから［送る］
   - 何の印も出ていない作品：GitHub に置き場が無い作品です。ここで止めて、母艦に作品の名前を伝えてください（消すと戻せません）
4. 下のタブの［ほか］→［書きかけの控え］を押す。何も並んでいなければよい。何か並んでいたら、どの話にも戻せなかった書きかけです。入れ直すと消えるので、ここで止めて母艦に伝えてください（パソコンへ写してから進めます）
5. 全部「同期済み」になったら、母艦に「送り終えた」と伝えてください

## 5. 入れ直す（AQUOS。4. が全部済んでから）

1. AQUOS をパソコンに USB でつなぐ（いつものケーブル）
2. ホームの画面で、モバイル版のアイコンを長く押す →［アンインストール］→［OK］（この操作で端末の中の作品は消えます。4. が済んでいることを、もう一度確かめてから）
3. 母艦に「消した」と伝える。モバイル版のセッションが、Release の新しい版をパソコンから入れます
4. アプリを開き、下のタブの［ほか］→［GitHub と同期］→［サインイン］。出た8字のコードで、ブラウザから GitHub に入れて許す
5. 下のタブの［作品］→ 右下の［＋］→［GitHub から取り寄せる］→ 作品を一つずつ押して取り寄せる
6. AI を使うなら、［ほか］→［AI］で鍵を入れ直す。字の大きさなどは［ほか］→［表示］で選び直す
7. ［ほか］→［更新］を押し、今の版が新しい版になっていることを見る

これより後の版は、アプリの中の知らせの［入れる］から入れられます（初めの1回だけ、端末が「このアプリからの入れ替え」を許すかを訊きます）。
