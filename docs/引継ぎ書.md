## 1. 共有する部品はいつも本体と同じ版で取り込む

**【決定】** 2026-11-04 作者の裁定（母艦「0.125.4 母艦引継ぎ」から伝達）：本体と共通の部品（`src/models/`・`src/core/`）は「いつも本体と同じ版」で取り込む。本体の版が上がるたびに同じ部品を取り込み、モバイル版を出し直す。

**理由**：作品フォルダーの `設定/` は GitHub で同期するので、本体とモバイル版が同じ台帳を読み書きする。古い部品は台帳の知らない欄を落として書き戻すので、モバイル版が古いままだと、本体で増えた欄が同期で消える。0.123.0〜0.125.4 で投稿の台帳（`models/posting.ts`）に増えた欄（`posts[]` の bodyHash・titleHash・siteEpisodeId・postRef、台帳の revisions、siteFacts の siteWorkNumber）はその例で、本体の注記にも「この欄を知らない古い版が保存すると消える」とある。

`src/ai/`・`src/prompts/` も共有する（設計書 2.2）。台帳を書く部品ではないが、同じ版で取り込む。版をばらばらに持つと、どの組み合わせで確かめたか分からなくなるためである。

## 2. 取り込みの段取り

2026-11-05 に本体 v0.126.2 を初めて取り込み、同じ日に v0.127.0 へ上げた（いま取り込んでいるのは v0.127.0）。仕組みは**本体のタグを指す依存**（`package.json` の `"novel-ai-assistant": "github:nonahisa/novel-ai-assistant#v0.127.0"`）。ワークスペースと比べて決めた中身は設計書 2.2。画面のコードは本体の部品を `src/shared.ts` を通して読む。取り込みも版上げも、次の段取りを守る。

1. **取り込む前に母艦へ一言送る**（母艦の求め 2026-11-04）
2. **本体の版を決める**：本体の `package.json` の `version` と、それに対応するタグ（`vX.Y.Z`）。タグがまだ打たれていない版は取り込まない（2026-11-04 時点で `package.json` は 0.125.4、タグは v0.125.3 まで）
3. **写しを作らない**：本体のソースをそのまま参照する。モバイル版の側で共有の部品を直さない。直したいところは母艦へ伝え、本体で直してもらってから取り込む
4. **取り込んだ版を1か所に記す**：`package.json` の `novel-ai-assistant` の `#vX.Y.Z` が唯一の置き場（`pnpm-lock.yaml` が commit まで固定する）。版を上げるのは `pnpm add "novel-ai-assistant@github:nonahisa/novel-ai-assistant#vX.Y.Z"` の1行。画面の動作確認ページの「本体の部品」の行に、取り込んだ版が出る
5. **確かめる**：`pnpm run typecheck`・`pnpm run test`（本体と同じテストを、差し替えた部品にも通す。設計書 9章）・`androidReach.test.ts`（端末で使えない部品を取り込んでいないか。設計書 2.4）
6. **出し直す**：APK を作り直す（`pnpm run apk`。CI でも同じ。iOS は `pnpm run sync:ios`）。版の付け方は出し直しの段取りと一緒に決める
7. **差し替えた部品も追いつかせる**：`core/postingStore.ts` のように vscode に頼る部品は、モバイル版で差し替える（設計書 2.3）。本体でその部品の中身が変わったら、差し替えた側も同じに直す。たとえば 0.124.0 から、投稿の台帳を書くときに revisions を名指しで書いている。これを落とすと、保存で消える

**投稿の台帳を読む機能を載せる前に、本体のタグ v0.127.0 以降へ上げる**（母艦から 2026-11-05）。本体 0.127.0 で投稿の記録に新しい印（`v3:`）が入り、0.127.0 より前の core では `設定/投稿状態.json` を開けなくなる。2026-11-05 に v0.127.0 へ上げて済んだ（`test/shared.test.ts` が `v3:` の印のある台帳を読めることを見る）。これからも、本体で台帳の印や欄が変わる版は、台帳を読み書きする前に必ず追いつく。

**本体の版が上がったら**：2〜7をもう一度通す。本体の版上げを母艦から知らされたとき、または母艦から頼まれたときに始める。
