## 4. iOS（Mac・Xcode で `pnpm run ios` を走らせてから）

Android の確認と同じ項目を、iPhone（WKWebView）でも見る。WebKit は Chromium と挙動が違うので、別に見る。

- [ ] 縦書きの入力欄で、日本語変換の候補が出て、確定しても字が消えないか →〔作者の手：要・iPhone 実機〕
  - ✔ 2026-11-02 作者の確認（iOS シミュレーター）：**変換中の未確定の下線は縦書きで左側に出る。** CSS の既定（傍線は右）とは逆。ルビ・傍点は右側なので重ならない。左側に置くもの（道具帯の並びや行番号など）を決めるときは、この前提で考える
- [ ] キーボードが出たとき、縦書きの原稿欄が隠れず、カーソルの行が見えるか（iOS は resize が来ないことがあるため、「見えている高さ」の数字が変わるかも見る） →〔作者の手：要・iPhone 実機〕
- [ ] 横向きでノッチ側に文字や操作が入り込まないか（左右の safe-area） →〔作者の手：要・iPhone 実機〕
- [ ] ルビと傍点が縦書きで正しい向きに出るか →〔作者の手：要・iPhone 実機〕
- [ ] 「保存して読み戻す」が通るか。日本語のファイル名（確認/原稿.txt）が Documents に作られるか →〔作者の手：要・iPhone 実機〕
