## 作者に押してもらう手順（iPad・Android とも同じ）

始める前に：まだ一度も［保存して読み戻す］を押していなければ、欄には見本の文が入っています。前に保存していれば、その文が出ます。どちらでも試せます（見本の文で書いてあります）。

1. ホーム画面で「モバイル版」のアイコンを押す
2. 画面のいちばん下の4つのタブのうち、左から2つめの［書く］（ペンの絵）を押す
3. 「試し」という小見出しの下の［縦書き・横書きの試し］を押す
4. 上のほうの1段め［縦書き］［横書き］のうち、［縦書き］が色付きになっていることを見る（なっていなければ押す）
5. 2段めの［A いまの形］［B 右傍線］［C 組んで書く］のうち、右の［C 組んで書く］を押して、色付きにする
6. 原稿の欄の1行目（いちばん右の列）のいちばん上に「吾輩」があり、右に小さく「わがはい」と振り仮名が付いていることを見る。2行目の「頓と」の右には点（傍点）が付いている

**試し1　塊のすぐ後に打つ**
7. 「吾輩」と、そのすぐ下の「は」との間を、指で押す（キーボードが出ます）
8. 「ねこ」と打ち、変換して確定する
9. 「吾輩」と振り仮名がそのまま残り、そのすぐ下に打った字が入ったかを見る

**試し2　塊のすぐ前に打つ**
10. 「吾輩」のすぐ上（1行目の列のいちばん上）を押す
11. 「「」（かぎかっこ）を打って確定する
12. 「吾輩」の上に「「」が入り、「吾輩」と振り仮名が崩れていないかを見る

**試し3　⌫ で塊ごと消す**
13. 「吾輩」のすぐ下を押す
14. キーボードの ⌫（1字消す）を1回だけ押す
15. 「吾輩」と振り仮名がまとめて消え、ほかの字は残ったかを見る

**試し4　塊を押す**
16. 2行目の、点の付いた「頓と」の字の真ん中を押す
17. カーソル（点滅する線）が「頓と」の上か下に来たか、「頓」と「と」の間に入って見えたかを見る

**試し5　［ルビ］の窓**
18. 1行目の「猫」の字を長押しして、「猫」1字だけを選ぶ（選ぶ範囲のつまみで1字に合わせる）
19. 原稿の欄の上にある［ルビ］を押す
20. 「「猫」の読み」と書いた窓が出るので、「ねこ」と打って変換し、確定する（確定しても窓は閉じないはず）
21. 窓の［決める］を押す
22. 「猫」の右に「ねこ」と振り仮名が付いたかを見る

**試し6　［傍点］**
23. 1行目の「名前」を長押しして、「名前」の2字を選ぶ
24. ［傍点］を押す
25. 「名前」の右に点が付いたかを見る

**あと片付け**
26. 原稿の欄の下の［読み直す］を押す。「保存していない書き換えを捨てて、読み直しますか？」と出たら［捨てて読み直す］を押す（試しの文だけが元に戻ります。作者の原稿には触りません）

## 訊くこと（選択肢の案）

- 問1（試し1・2）：塊のすぐ後とすぐ前に打てましたか　…　両方できた／後ろだけできた／前だけできた／どちらもおかしかった
- 問2（試し3）：⌫ を1回押したとき　…　塊だけまとめて消えた／ほかの字も消えた／消えなかった
- 問3（試し4）：塊を押したとき、カーソルは　…　塊の上か下に来た／塊の字の間に入って見えた／離れた所へ飛んだ
- 問4（試し5・6）：［ルビ］［傍点］は　…　両方できた／ルビの窓が確定で閉じた・打てなかった／振れない・付かないものがあった

## 記録（trial-log）の読み方

縦書きの試しの記録は、iPad は Documents、Android はアプリの領域にある（画面の「変換の知らせの記録」の中にファイルの名前が出る）。iPad は Mac のセッションが devicectl で取り出す。Android は USB でつないで adb で取り出す。

| 行の頭 | 見ること |
|---|---|
| `C 組んだ（塊 N つ）` | C に入ったときに組めた。`C 往復が合わなかったので…` なら組まずに記法のまま（安全弁） |
| `C 押した（点 x/y、touch）：n字目（ルビ「吾輩」の直後）` | 押した所が、塊の直前・直後・地の字のどれになったか（試し1・2・4） |
| `C カーソルを塊の外へ置き直した：…` | 端末が塊の中にカーソルを置き、こちらで外へ出した（試し4） |
| `C 変換の始まり：…`・`C 確定「ねこ」のあと：n字目（…）` | 変換の前後でカーソルがどこにあったか。確定のあとが「ルビ「吾輩」の直後」より後ろなら、塊の後ろに入った（試し1） |
| `C ⌫ で塊を消した（{吾輩|わがはい}）` | ⌫ をこちらで受けて塊ごと消した（試し3）。この行が無く本文が変わっていれば、端末が自分で消した |
| `C 組み直した（…）` | 打ったあとに欄の形が崩れていたので組み直した。変換の直後に続くなら、その端末の日本語入力が塊の隣で欄を崩している |
| `C ルビを振った（{猫|ねこ}）`・`C 傍点を付けた（{{名前}}）` | ［ルビ］［傍点］が効いた（試し5・6） |

## AQUOS（Android）へ入れる・記録を取り出す（このパソコンで。作者が USB でつないでから）

作者の手：AQUOS をデータの通る線でこのパソコンにつなぎ、画面のロックを外しておく（［開発者向けオプション］→［スリープモードにしない］を入れてあれば、つないでいるあいだ画面が消えない。引継ぎ書 25章）。以下はパソコンのセッションが打つ（リポジトリの頭で。JAVA_HOME は Temurin 21）。

1. つながっているか：`pnpm run devices`（`adb devices -l` に AQUOS が `device` と出る）
2. 組み立てる：`pnpm run apk`（`android/app/build/outputs/apk/debug/app-debug.apk` ができる）
3. 入れる（前の版の上に入れる。試しの原稿と選び方は残る）：

   ```
   adb install -r android/app/build/outputs/apk/debug/app-debug.apk
   ```

4. 入った版を見る：`adb shell dumpsys package com.nonahisa.novelai | grep versionName`（`versionName=0.1.24` など）。アプリの画面の上にも「モバイル版 0.1.24」と出る
5. 記録の取り出し：記録はアプリの領域の `files/trial-log/`（試しの画面を開くたびに `ime-log-<日時>.txt` が1つ増える）。組み立てが debug なので `run-as` で読める

   ```
   adb shell run-as com.nonahisa.novelai ls -l files/trial-log
   adb exec-out run-as com.nonahisa.novelai cat files/trial-log/ime-log-20261113-153000.txt > trial-log-aquos.txt
   ```

   名前は1行目の一覧から、作者が試した時刻のものを選ぶ。取り出したファイルはリポジトリに入れない（スクラッチか `docs/画面の写真/` のような .gitignore の所に置く）
