# 統合小説執筆環境 モバイル版（Android・iOS）

スマホやタブレットで、縦書きの小説を書くアプリです。パソコン版（VS Code の拡張機能「統合小説執筆環境」）と同じ作品フォルダーを、GitHub を通して行き来できます。

## できること

- 縦書きの原稿エディターで書けます。横書きにも切り替えられます。ルビと傍点を付けられ、キーボードの上の道具帯も使えます。書いた字は自動で保存され、取り消しとやり直しもできます。
- 作品の一覧と話の一覧に、題・話数・字数・最後に書いた日を出します。
- GitHub と同期して、パソコン版と同じ作品を取ってきたり送ったりできます。両方で書き換えていたときは、どちらを残すかを話ごとに選べます。
- あらすじ、誤字脱字の指摘、推敲を AI に頼めます。指摘は［提案］に並ぶので、［採る］か［見送る］を選んでください。料金がかかる呼び出しの前には、見積もりを出して確かめます。
- 人物などの設定資料を読めます。本文から資料を読み直したり、人物どうしの関係を見たりもできます。
- 執筆統計に、今日と今週の字数と、直近14日の字数のグラフを出します。
- 原稿の字の大きさは2本指で広げたりつまんだりして変えられます。書体は［ほか］→ 表示 で選べ、明朝体（Noto Serif JP）はあとから取り寄せられます。

## 使い方

### 1. GitHub にサインインする

1. 下のタブの［ほか］を押します。
2. ［GitHub と同期］を押します。
3. ［サインイン］を押すと、8字のコードが出ます。
4. ［コードを写して GitHub を開く］を押します。ブラウザで GitHub が開くので、そのコードを貼り付けて許可します。

### 2. 作品を取り寄せる

1. 下のタブの［作品］を押します。
2. 右下の［＋］を押し、［GitHub から取り寄せる］を選びます。
3. リポジトリの一覧から作品を選びます。

新しく書き始めるときは、［＋］で［新しく作る］を選びます。

### 3. 書く

1. 下のタブの［作品］で作品を押し、話を押します。
2. 原稿エディターが開くので、そのまま書きます。保存は自動です。

### 4. 同期する

1. 下のタブの［作品］で、作品の横に出ている同期の札（「同期済み」など）を押します。
2. 同期の画面で［取ってくる］か［送る］を押します。

札が出ていない作品は GitHub とつながっていないので、同期できません。

### 5. AI を使う

1. 下のタブの［ほか］を押し、［AI］を押します。
2. 使う AI（Claude・ChatGPT・Gemini・さくらのAI）の API キーを登録します。キーは端末の鍵の置き場にしまいます。

AI の利用料はそれぞれの AI の会社から請求されます。

## 作品の置き場

作品はアプリ専用の領域に置きます。ほかのアプリからは見えません。パソコンとは GitHub を通して行き来します。
