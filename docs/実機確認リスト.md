## 4. iOS（Mac・Xcode で `pnpm run ios` を走らせてから）

Android の確認と同じ項目を、iPhone（WKWebView）でも見る。WebKit は Chromium と挙動が違うので、別に見る。シミュレーターで見られる所は、Mac のセッションに頼んで流してもらう（作者の手は要らない）。
